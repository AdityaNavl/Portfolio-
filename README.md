# Aditya — Portfolio

Personal portfolio site built to showcase my projects, skills, and background as I complete my MCA and look for Full Stack (MERN) Developer roles.

Live site: https://AdityaNavl.github.io/portfolio/

## About

I'm pursuing my MCA (graduating 2027) with a focus on full stack web development — React, Node.js, Express, and MongoDB. Alongside my coursework, I work as a Team Leader at The Prime Today Media, handling client communication and project coordination.

This site covers who I am, what I've built, what I'm currently learning, and how to reach me.

## What's included

- Responsive layout across mobile, tablet, and desktop
- Dark mode toggle
- Scroll-based navigation highlighting
- Filterable project section
- Contact form connected through EmailJS
- GitHub activity stats

## Stack

HTML5, CSS3, JavaScript (ES6+), Font Awesome, Google Fonts (Poppins), EmailJS

**Running it locally**

Open `index.html` directly in a browser, or run it through a local server (e.g. VS Code's Live Server extension).
